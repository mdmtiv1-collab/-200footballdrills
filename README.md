# +200 Football Drills Vault — High-Converting Landing Page

A modern, high-performance, and mobile-optimized landing page for the **+200 Football Drills Vault** practice app.

## 🚀 Features
- **Official NFL Shield Color Scheme**: Ateneo Blue (`#013369`), Authentic Red (`#D50A0A`), Silver/Gray, and Pure White.
- **Section 2 Infinite Marquee**: 6 Position-specific vertical posters from ChatGPT scrolling smoothly.
- **Section 6 Infinite Marquee**: 5 Tactical drill schematics with complete category tags and coaching goal explanations.
- **Dynamic 15-Minute Countdown Timer**: Resets in sessionStorage to create high-urgency conversions.
- **Live Social Proof Notifications**: Subtle, compact toasts displaying recent purchases in US cities.
- **Special $14.90 Upsell Popup Modal**: Triggers when clicking the Basic Plan button ($9.90).
- **Mobile-First Responsive Design**: Sticky bottom CTA bar, touch-friendly buttons, clamp typography, zero horizontal scroll.
- **100% Static & Lightweight**: Pure HTML5, CSS3, and Vanilla JavaScript with zero external runtime dependencies.

## 📦 How to Deploy

### 1. Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit - +200 Football Drills Landing Page"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
git push -u origin main
```

### 2. Deploy on Vercel
1. Go to [Vercel](https://vercel.com/) and click **"Add New..."** -> **"Project"**.
2. Import your GitHub repository.
3. Keep default settings (Framework: **Other / Static**) and click **Deploy**.
4. Your site will be live instantly with a free SSL certificate!
